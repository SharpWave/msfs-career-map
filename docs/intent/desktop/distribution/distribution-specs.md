# Distribution — EARS Specs

Design: [distribution-design.md](distribution-design.md), with the shared items
[desktop-design.md](../desktop-design.md) assigns to it. Prefix `DESK-DIST`; facets `PKG` (packaging:
the names and pinned tools the packaging configuration and `package.json` hold, the unit test of those
names, the desktop build output and electron-builder's output, what the program holds, the bundles, the
seed airport lists, their download times and when the build downloads them, the icons and the fuses),
`INST` (the installer: its wizard, first installs and installs over an installed copy, the mark it gives
the installed copy's uninstaller, the install folder, the folders it leaves alone, closing a running copy
for the installer and the uninstaller alike, silent installs and updates, holding the session end while
installing, the install-under-way mark and starting the app once an install is done), `UNINST` (the
uninstaller, on a real uninstall and as the installed copy's uninstaller run by an install over it),
`REL` (the release workflow, the tag it builds, draft releases and their hashes, broken releases, how
often releases ship, the first release's gates, manifest signing and a winget listing), `DEV` (`npm run
desktop`, only the installed program running outside test mode, the folders kept out of git, the
scripts clearing `ELECTRON_RUN_AS_NODE`, fetching Electron's binary in CI, the installed app's
shortcuts), `INCL` (the include's tests), `SMOKE` (the packaged smoke test and its check that port 3280
is free), `TRIP` (the installer round trip and its guard).

`[x]` implemented · `[ ]` intended, not yet implemented · `[D]` deferred

## Packaging

- [x] **DESK-DIST-PKG-001**: The electron-builder configuration shall set the appId, used also as the AppUserModelID, to `io.github.sharpwave.msfscareermap` (the uninstall entry's id and the update chain derive from it).
- [x] **DESK-DIST-PKG-002**: The electron-builder configuration shall keep the ToastActivatorCLSID, a GUID chosen once, beside the appId.
- [x] **DESK-DIST-PKG-003**: The electron-builder configuration shall set the product name "MSFS Career Map", which names the program `MSFS Career Map.exe`, the Start-menu entry and the entry in Windows' Apps list.
- [x] **DESK-DIST-PKG-004**: The project's `package.json` shall name the package `msfs-career-map`, so electron-updater's own download folder is `%LOCALAPPDATA%\msfs-career-map-updater`.
- [x] **DESK-DIST-PKG-005**: The electron-builder configuration shall build electron-builder's assisted NSIS installer, per user, as the app's only installer target.
- [x] **DESK-DIST-PKG-006**: The packaging names — the appId (`io.github.sharpwave.msfscareermap`), the ToastActivatorCLSID, the product name "MSFS Career Map", the package name `msfs-career-map`, the install folder (`%LOCALAPPDATA%\Programs\MSFS Career Map`) and electron-updater's download folder (`%LOCALAPPDATA%\msfs-career-map-updater`) — shall never change from one release to the next (desktop-design: the single-instance lock, the settings, the page's remembered choices, the uninstall entry, the update chain and the start-list entries are all found by them).
- [x] **DESK-DIST-PKG-019**: The distribution unit tests (`tests/desktop/distribution/`, Vitest in Node, no Electron) shall read the appId, the ToastActivatorCLSID and the product name from the electron-builder configuration and the package name from `package.json`, and fail when any differs from its fixed value (DESK-DIST-PKG-001 to DESK-DIST-PKG-004).
- [ ] **DESK-DIST-PKG-007**: The project's `package.json` shall pin Electron to an exact 45.x release, electron-builder to 26.18.0, electron-updater to 6.8.11 and esbuild to an exact version, with electron-builder and electron-updater installed by exact version, never by npm's `latest` tag (which can lag behind the newest release).
- [x] **DESK-DIST-PKG-022**: The desktop build scripts shall build into the desktop build output, `build/desktop/`, a folder apart from Vite's page build in `dist/` that nothing but those scripts empties, copying the page build in from `dist/` as `page/` after Vite has built it (laid out as app-shell's program folder, APP-SRV-006), and the electron-builder configuration shall set electron-builder's output folder to `release/`, never leaving it at electron-builder's default, `dist/` (Vite empties `dist/` at every page build, app-shell's `npm run build` among them).
- [x] **DESK-DIST-PKG-008**: The packaged program shall hold the page's Vite build as `page/` in the program's resources, outside the app archive (`app.asar`, the read-only file holding the app's code), beside the seed airport lists (DESK-DIST-PKG-012), as app-shell's program folder lays it out (APP-SRV-006: `page/` with its `index.html`, beside `airports.csv`, `runways.csv` and their `.downloaded` download times).
- [x] **DESK-DIST-PKG-009**: When the desktop build scripts run, whether to package the app or for `npm run desktop`, they shall bundle `src/server` with esbuild into an ES module, `server.mjs`, with its start-up worker as a second ES module, `startup-worker.mjs`, beside it, both with a `require` shim for their CommonJS dependencies and the version from `package.json` built in, so `/api/status` and every User-Agent the server sends report it (APP-API-005).
- [x] **DESK-DIST-PKG-010**: The server bundle shall leave out node-simconnect and its own dependencies, and the packaged program shall ship them as separate files outside the app archive (`app.asar`), with node-simconnect's LGPL-3.0 licence, so the library can be replaced.
- [x] **DESK-DIST-PKG-011**: When the desktop build scripts run, whether to package the app or for `npm run desktop`, they shall bundle `src/desktop` with esbuild into one CommonJS file, with the version from `package.json` built in.
- [x] **DESK-DIST-PKG-012**: When the desktop build scripts run, whether to package the app or for `npm run desktop`, they shall leave the desktop build output (`build/desktop/`, DESK-DIST-PKG-022) holding OurAirports' `airports.csv` and `runways.csv` as the seed airport lists, each with the time it was downloaded recorded beside it in the form airports reads (`<list>.downloaded`, an ISO 8601 UTC time ending in `Z`, with seconds, APT-DATA-018), laid out there exactly as packaging lays them out in the packaged program's resources (the program folder is the packaged program's resources when packaged — installed, or the unpacked build in `release/` the smoke test runs — and the desktop build output when unpackaged; airports seeds a data folder lacking the lists from the program folder's (APT-DATA-017), so the first start on a new data folder — the installed app's, or `npm run desktop`'s on a fresh `.desktop-dev\` — needs no connection, and its monthly refresh counts from each list's recorded download time, APT-DATA-003).
- [x] **DESK-DIST-PKG-020**: When the desktop build scripts run, whether to package the app or for `npm run desktop`, and the desktop build output (`build/desktop/`) lacks either seed airport list (`airports.csv`, `runways.csv`) or the recorded time it was downloaded, or the scripts were given `--fresh`, they shall download both lists from OurAirports into the desktop build output, replacing any already there, and record with each the time of that download (in the form APT-DATA-018 gives).
- [x] **DESK-DIST-PKG-021**: When the desktop build scripts run without `--fresh`, whether to package the app or for `npm run desktop`, and the desktop build output (`build/desktop/`) already holds both seed airport lists (`airports.csv`, `runways.csv`) with their recorded download times, they shall keep those lists and their times and download nothing (so a rebuild needs no connection).
- [x] **DESK-DIST-PKG-013**: The packaged program shall hold nothing used only to build or develop: tsx, Vite and the page's libraries shall stay out of the package.
- [x] **DESK-DIST-PKG-014**: The packaged program shall hold every Chromium locale, so dates and numbers follow the pilot's Windows language.
- [x] **DESK-DIST-PKG-015**: The packaged program, the installer and the shortcuts the installer makes shall use `career-map.ico` as their icon, holding a 256 px image.
- [x] **DESK-DIST-PKG-016**: The packaged program shall hold the tray icons, each holding 16, 20, 24 and 32 px images: the app's mark with no dot, and the mark with each of the tray icon's status dots, red, blue, violet, amber and green (DESK-SHELL-TRAY-013 says when each one shows).
- [x] **DESK-DIST-PKG-017**: The packaged program shall be built with Electron's RunAsNode and `NODE_OPTIONS` fuses off, so that neither `ELECTRON_RUN_AS_NODE` nor `NODE_OPTIONS`, when set, changes what the installed program runs.
- [x] **DESK-DIST-PKG-018**: The packaged program shall be built with Electron's inspect fuses on (the packaged smoke test drives the app through them).

## Installer

- [x] **DESK-DIST-INST-001**: The installer shall install for the current Windows user only, needing no administrator rights, and shall offer no choice of install folder.
- [ ] **DESK-DIST-INST-002**: The installer's wizard shall show, in order, the licence page (only where the repository has a licence), Installing and Finished, and no other page.
- [x] **DESK-DIST-INST-003**: The installer shall skip electron-builder's page asking whether to install for everyone or only the current user, the app's NSIS include (`build/installer.nsh`) choosing the current user through electron-builder's `customInstallMode` hook.
- [x] **DESK-DIST-INST-004**: When the installer runs with its wizard as a first install (no copy of the app installed), its Finished page shall show two boxes, both ticked: "Create a desktop shortcut" and "Launch MSFS Career Map now".
- [x] **DESK-DIST-INST-005**: When the pilot finishes the installer's wizard on a first install (no copy of the app installed), the installer shall create the desktop shortcut only if "Create a desktop shortcut" is ticked, and start the installed app, with no command-line switch, only if "Launch MSFS Career Map now" is ticked.
- [ ] **DESK-DIST-INST-018**: When the installer, run with its wizard, installs over an installed copy of the app (an update, a repair with the same version's installer, or an older installer), its Finished page shall show one box, "Launch MSFS Career Map now", ticked, and no "Create a desktop shortcut" box (an install over an installed copy keeps the shortcuts as the pilot left them, DESK-DIST-INST-008).
- [ ] **DESK-DIST-INST-019**: When the pilot finishes the installer's wizard over an installed copy of the app (an update, a repair with the same version's installer, or an older installer), the installer shall start the installed app with no command-line switch if "Launch MSFS Career Map now" is ticked, and otherwise only as a start made while it installed asks (DESK-DIST-INST-026).
- [ ] **DESK-DIST-INST-006**: When the installer runs as a first install (no copy of the app installed), with its wizard or silently, it shall add the Start-menu entry "MSFS Career Map", carrying the AppUserModelID `io.github.sharpwave.msfscareermap`.
- [x] **DESK-DIST-INST-020**: The installer, on a first install and on every install over an installed copy, run with its wizard or silently, shall write the app's uninstall entry in Windows' Apps list.
- [x] **DESK-DIST-INST-007**: When the installer runs silently as a first install (no copy of the app installed), it shall create the Start-menu entry and the desktop shortcut and shall not start the app.
- [x] **DESK-DIST-INST-008**: When the installer installs over an installed copy of the app — an update, silently from electron-updater or by the pilot running a newer installer, a repair with the same version's installer, or an older installer run by hand — with its wizard or silently, it shall keep the Start-menu entry and the desktop shortcut as the pilot left them, neither recreating one the pilot deleted nor removing one the pilot kept.
- [x] **DESK-DIST-INST-023**: When the installer installs over an installed copy of the app — an update, silently from electron-updater or by the pilot running a newer installer, a repair with the same version's installer, or an older installer run by hand — with its wizard or silently, it shall first run that copy's uninstaller silently with `--updated` on its command line, the mark by which the uninstaller knows it is run by an install over the installed copy (DESK-DIST-UNINST-015), so it skips `--unregister` and leaves the shortcuts and electron-updater's download folder (DESK-DIST-UNINST-003, DESK-DIST-UNINST-006, DESK-DIST-UNINST-014).
- [x] **DESK-DIST-INST-024**: When the installer finishes a silent install over an installed copy of the app (an update, a repair or an older installer, the pilot's own `/S` among them), it shall start the app only as DESK-DIST-INST-026 says — the start the desktop shell asked for when it handed over, or one made while the install ran — and otherwise leave it stopped, even when it closed a running copy to install.
- [ ] **DESK-DIST-INST-027**: While the installer installs over an installed copy of the app (an update, a repair or an older installer), with its wizard or silently, the app's NSIS include shall hold the end of the Windows session with the reason "Installing an update to MSFS Career Map" — a hidden window of its own refusing Windows' query to end the session — from the start of that install until it is done or stops (ended between the installed copy's uninstaller removing the program, DESK-DIST-UNINST-004, and the new files landing, the install would leave no program to start).
- [x] **DESK-DIST-INST-009**: The installer shall always install the program in `%LOCALAPPDATA%\Programs\MSFS Career Map`.
- [x] **DESK-DIST-INST-010**: If the installer's command line gives an install folder other than `%LOCALAPPDATA%\Programs\MSFS Career Map` with `/D=`, then the installer shall stop before it installs anything, leaving nothing behind — the empty folder electron-builder's start makes for the folder given is taken away again (so the uninstaller, which removes the install folder and everything in it, can never reach the data folder, the backups folder or Electron's own folder).
- [x] **DESK-DIST-INST-021**: The installer, on a first install or an install over an installed copy (an update, a repair or an older installer), run with its wizard or silently, shall itself write, change or delete nothing in the data folder (`%LOCALAPPDATA%\MSFS Career Map`), the backups folder (`MSFS Career Map\Backups` in Documents) or Electron's own folder (`%APPDATA%\MSFS Career Map`) (the backup a running copy takes at `--quit`, DESK-SHELL-CLI-008, is the app's own).

## Closing a Running Copy

- [x] **DESK-DIST-INST-022**: The app's NSIS include (`build/installer.nsh`) shall implement electron-builder's `customCheckAppRunning` hook, replacing electron-builder's own check for a running copy entirely, for the installer and the uninstaller alike, and shall never lock an installed file to find a running copy.
- [x] **DESK-DIST-INST-011**: The installer and the uninstaller shall each take as the app's running copy only the processes, running for the current Windows user, whose program path lies inside the install folder (`%LOCALAPPDATA%\Programs\MSFS Career Map`) — the desktop shell and its server's utility process alike, a test-mode copy of the installed program (`--test-data=<folder>`) among them — leaving alone a copy running from anywhere else, such as a smoke-test build.
- [ ] **DESK-DIST-INST-012**: When the installer or the uninstaller, run with its wizard, finds the app's running copy (processes inside the install folder, DESK-DIST-INST-011), it shall say, with OK and Cancel, that MSFS Career Map will be closed — the installer adding that it records nothing until it starts again, and the uninstaller (run with its wizard only for a real uninstall, after which the app does not start again) saying nothing more.
- [ ] **DESK-DIST-INST-013**: When the pilot chooses Cancel at the installer's or the uninstaller's notice that MSFS Career Map will be closed, the wizard shall stop without closing the running copy.
- [x] **DESK-DIST-INST-014**: While the installer or the uninstaller runs silently, it shall ask nothing before closing the app's running copy.
- [x] **DESK-DIST-INST-015**: When the installer or the uninstaller closes the app's running copy (after OK, or at once when silent), it shall first run the installed program with `--quit` (DESK-SHELL-CLI-008: the running copy takes its backup, shuts its server down cleanly and exits, asking nothing and installing no ready update).
- [x] **DESK-DIST-INST-016**: When the installer or the uninstaller has run the installed program with `--quit`, it shall wait up to 90 s for every process of the app's running copy (DESK-DIST-INST-011) to end, then end any still running, before going on (a test-mode copy of the installed program, which the `--quit` never reaches since its single-instance lock is in its own folder, DESK-SHELL-CLI-010, is ended this way once the 90 s are over).
- [D] **DESK-DIST-INST-017**: If a silent installer run finds the app's running copy (DESK-DIST-INST-011) with the sim in use (DESK-SHELL-AWAY-001: this copy's sim link connected, another copy holding the PC-wide sim-link claim, or MSFS — `FlightSimulator2024.exe` or `FlightSimulator.exe` — running for this Windows account), then the installer shall leave the app running, in place of closing it as DESK-DIST-INST-014 to DESK-DIST-INST-016 say, and exit with an "application in use" code.

## An Install Under Way

- [ ] **DESK-DIST-INST-025**: When the desktop shell is about to hand over to the installer — at the end of a Quit with an update ready, a **Restart to update** (with or without a backup) or a quiet-moment install — the install-under-way mark shall be in place before the desktop shell's last look for starts handed over (DESK-SHELL-QUIT-006) and before it releases the single-instance lock: a file `install-under-way` in electron-updater's download folder (`%LOCALAPPDATA%\msfs-career-map-updater`), written whole by the desktop shell (DESK-SHELL-UPD-031) and from then on only appended to, one line at a time, never rewritten, in the mark's form (distribution-design, An install under way: UTF-16LE, one record per line, `process`, `request` and `start` records), holding the desktop shell's process (its process id and program path) and the start the desktop shell asks for once the install is done — `--updated` after **Restart to update** (DESK-SHELL-UPD-012, DESK-SHELL-UPD-030), `--background` after a quiet-moment install (DESK-SHELL-UPD-028) unless the pilot chose Quit during it (DESK-SHELL-QUIT-011), and none after a Quit (DESK-SHELL-UPD-011) — the last requested start in the mark counting, so the requested start of none the desktop shell adds for a Quit held after the mark is written (DESK-SHELL-UPD-031) takes the place of `--background`; and the mark shall be taken up — by the include at the end of an install (DESK-DIST-INST-026), or by the desktop shell when the install goes no further (DESK-SHELL-UPD-031) — only by renaming it aside, then reading and deleting the renamed file, so a line a start appends meanwhile is either read or met by that start's own second look (DESK-DIST-INST-030).
- [x] **DESK-DIST-INST-029**: When the installer installs over an installed copy of the app (an update, a repair or an older installer), with its wizard or silently, the app's NSIS include shall, before it closes the app's running copy (DESK-DIST-INST-015) — after OK on the wizard's notice, or at once when silent — mark the install as under way (DESK-DIST-INST-025) with the installer's own process (its process id and program path): when the installer was started from electron-updater's download folder (`%LOCALAPPDATA%\msfs-career-map-updater`, the desktop shell's own install), by appending a line naming that process to the mark in place, keeping the start asked for and any command lines starts have added, or by writing a new mark naming it where none is in place; otherwise by writing a new mark naming it in place of any other (so an installer the pilot runs by hand is marked too).
- [x] **DESK-DIST-INST-030**: A start of the app outside test mode (no `--test-data=<folder>`) shall count an install as under way (DESK-SHELL-CLI-020) only while the install-under-way mark (DESK-DIST-INST-025, DESK-DIST-INST-029) is in place and either a process it names — that process id running that program — or an installer started from electron-updater's download folder (`%LOCALAPPDATA%\msfs-career-map-updater`) runs for this Windows user, ignoring a mark with neither running (one left by an install that a session end or a crash cut off); such a start shall add its own command line to the mark as one line appended to the file, opening it for appending only and never creating it, so starts made at the same moment — MSFS and Windows sign-in, say — each keep theirs, and then look for the mark again: still in place, the start exits, its line left for whoever takes the mark up (DESK-DIST-INST-026, DESK-SHELL-UPD-031); gone, or gone before its line could be added — taken up meanwhile — the start counts the install as over and starts as usual (should its line also have been read, the app is started twice and the second start hands its command line over to the first, DESK-SHELL-CLI-003).
- [ ] **DESK-DIST-INST-026**: When an install over an installed copy of the app is done, with its wizard or silently, the app's NSIS include shall take up the install-under-way mark (DESK-DIST-INST-025: renamed aside, then read and deleted) and only then start the app, at most once, with the command line that shows the most — no switch, then `--updated`, then `--background` — among the start the desktop shell asked for in the mark (the last requested), each command line a start added to the mark while the install ran (DESK-DIST-INST-030), and, run with its wizard, "Launch MSFS Career Map now" when ticked (a start with no switch, DESK-DIST-INST-019, which is then that one start), starting nothing when there is none of these (so the start it makes never finds the install still under way).
- [ ] **DESK-DIST-INST-028**: The first release shall carry the check for an install under way (DESK-SHELL-CLI-020, DESK-DIST-INST-030) and the desktop shell's mark before it hands over (DESK-DIST-INST-025, DESK-SHELL-UPD-031) in its program, and the install-under-way mark and the start after an install (DESK-DIST-INST-026, DESK-DIST-INST-029) in its include, since a start made during an install runs whichever program is then in the install folder — the old one as often as the new — and the desktop shell that hands over is the version already installed, so a change to these steps protects installs only one release late.

## Uninstaller

- [x] **DESK-DIST-UNINST-015**: The uninstaller shall take a run with `--updated` on its command line (the mark the installer gives the installed copy's uninstaller, DESK-DIST-INST-023) as the installed copy's uninstaller run by an install over it (an update, a repair or an older installer), and any run without it as a real uninstall (the pilot uninstalling the app).
- [ ] **DESK-DIST-UNINST-001**: The uninstaller shall close the app's running copy (DESK-DIST-INST-011 to DESK-DIST-INST-016 and DESK-DIST-INST-022) before it runs `--unregister` or removes anything.
- [x] **DESK-DIST-UNINST-002**: When the uninstaller runs for a real uninstall (the pilot uninstalling the app, not the installed copy's uninstaller run by an install over it — an update, a repair or an older installer), it shall run the installed program with `--unregister` before removing it (DESK-SHELL-CLI-009: that start does its work itself, without handing over — taking the app's entries out of `EXE.xml` and both of Windows' start-up keys, DESK-START-UNREG-001 and DESK-START-UNREG-002, and removing its notification registrations, DESK-SHELL-NOTE-017 — and exits within 15 s, DESK-START-UNREG-005), waiting up to 30 s for it to exit and then going ahead regardless.
- [ ] **DESK-DIST-UNINST-003**: While the uninstaller runs as the installed copy's uninstaller, run by an install over it (an update, a repair or an older installer), it shall skip `--unregister`.
- [x] **DESK-DIST-UNINST-004**: The uninstaller, whether for a real uninstall or as the installed copy's uninstaller run by an install over it (an update, a repair or an older installer), shall remove the install folder (`%LOCALAPPDATA%\Programs\MSFS Career Map`) and everything in it, and the app's entry in Windows' Apps list.
- [x] **DESK-DIST-UNINST-013**: When the uninstaller runs for a real uninstall (the pilot uninstalling the app, not the installed copy's uninstaller run by an install over it — an update, a repair or an older installer), it shall remove the Start-menu entry "MSFS Career Map" and the desktop shortcut.
- [x] **DESK-DIST-UNINST-014**: While the uninstaller runs as the installed copy's uninstaller, run by an install over it (an update, a repair or an older installer), it shall leave the Start-menu entry and the desktop shortcut as they are (an install over an installed copy keeps them as the pilot left them, DESK-DIST-INST-008).
- [x] **DESK-DIST-UNINST-005**: When the uninstaller runs for a real uninstall (the pilot uninstalling the app, not the installed copy's uninstaller run by an install over it — an update, a repair or an older installer), it shall remove electron-updater's download folder, `%LOCALAPPDATA%\msfs-career-map-updater`.
- [x] **DESK-DIST-UNINST-006**: While the uninstaller runs as the installed copy's uninstaller, run by an install over it (an update, a repair or an older installer), it shall leave electron-updater's download folder (`%LOCALAPPDATA%\msfs-career-map-updater`, which holds the running installer when electron-updater installs an update).
- [x] **DESK-DIST-UNINST-007**: The uninstaller, whether for a real uninstall or as the installed copy's uninstaller run by an install over it (an update, a repair or an older installer), shall itself write, change or delete nothing in the data folder (`%LOCALAPPDATA%\MSFS Career Map`), the backups folder (`MSFS Career Map\Backups` in Documents) or Electron's own folder (`%APPDATA%\MSFS Career Map`) (what lands there while it runs is the app's own doing: the running copy's backup at `--quit`, DESK-SHELL-CLI-008; and `--unregister`'s `desktop.log` entries, DESK-START-UNREG-004, its start-up list backups, DESK-START-MSFS-029 and DESK-START-WINDOWS-002, and its change to the settings' record of the `EXE.xml` files last written, DESK-START-UNREG-007).
- [ ] **DESK-DIST-UNINST-008**: When the uninstaller, run with its wizard for a real uninstall, finishes, its last page shall name the data folder (`%LOCALAPPDATA%\MSFS Career Map`), the backups folder (`MSFS Career Map\Backups` in Documents) and Electron's own folder as a whole (`%APPDATA%\MSFS Career Map`: the settings, logs, caches and the start-up list backups), saying they were kept and can be deleted by hand.
- [ ] **DESK-DIST-UNINST-009**: When, on a real uninstall run with its wizard, `--unregister` exits with a code saying a start list still holds the app's entry or could not be checked (DESK-START-UNREG-006: 0 when nothing of the app's is left in either start list; 1 when an `EXE.xml` still holds the app's entry or could not be checked; 2 when Windows' start-up keys still hold the app's value or could not be checked; 3 both), the uninstaller's last page shall say, for each start list the code names, that it still holds the app's entry or could not be checked, and name where the entry named "MSFS Career Map" can be removed by hand: for an `EXE.xml`, both MSFS editions' `EXE.xml` folders (DESK-START-MSFS-002; Store: `%LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalCache`; Steam: `%APPDATA%\Microsoft Flight Simulator 2024`); for Windows' start-up keys, the Run key (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) alone, since a value left under StartupApproved with none in Run starts nothing.
- [ ] **DESK-DIST-UNINST-010**: If, on a real uninstall run with its wizard, `--unregister` cannot be started, does not exit within 30 s, or exits with a code the uninstaller does not know, then the uninstaller's last page shall say the start lists could not be checked, and name as places where an entry named "MSFS Career Map" may need deleting by hand both MSFS editions' `EXE.xml` folders (DESK-START-MSFS-002; Store: `%LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalCache`; Steam: `%APPDATA%\Microsoft Flight Simulator 2024`) and Windows' Run key (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- [ ] **DESK-DIST-UNINST-011**: While the uninstaller runs silently, it shall show nothing and write no log of its own (`--unregister` writes its outcome to `desktop.log`, DESK-START-UNREG-004).
- [ ] **DESK-DIST-UNINST-012**: The first release's uninstaller shall carry every step of DESK-DIST-UNINST-001 to DESK-DIST-UNINST-011 and DESK-DIST-UNINST-013 to DESK-DIST-UNINST-015, closing a running copy and reading the `--updated` mark included, since every install over an installed copy runs that copy's uninstaller, so a change to those steps takes effect one release late.

## Releases
